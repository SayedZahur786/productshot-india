# Decisions
- 2026-11-21: isolated repository; root ignore already excludes all project folders. Shared kit unchanged.
- Use browser-side IMG.LY segmentation; model download can be slow on first use. Project license must remain compatible with its AGPL dependency, so use AGPL-3.0-only.
- Use two square export presets: Amazon 2000 px and Meesho 1080 px. These are practical export sizes, not a promise of marketplace acceptance or category compliance.
- Three fixed scenes: white, warm studio and mint shelf. No custom generation.
- Anonymous secure cookie accounts: no email collection. Lost cookies lose account access; clearly disclose before purchase. Durable identity is needed before commercial launch.
- Use a real Playwright walkthrough with system TTS and burned-in captions for the demo; this demonstrates actual UI behavior and avoids representing marketing animation as product evidence.
- GitHub authentication initially reports invalid credentials. Retry once with permitted network before classifying as an account blocker.
- Neon CLI is authenticated. Organization creation is not exposed by its API. Created a fresh isolated project in the existing authorized organization instead: org-sweet-wildflower-67376060 / spring-math-65762151 (Singapore). A new organization, if strictly required, remains a human console step. No other app shares this project.
- Real Unsplash photos replace authored illustrations. Their capture devices are unverified, so do not call them phone-shot originals. Seed segmentation uses local U2NetP; user uploads use the browser model. Both feed the same composition pipeline.
- The current environment rejects Turbopack's local worker port even after elevated execution. Use supported Webpack for the build; run the shared performance gate unchanged and report its own compiler result.
- Replaced IMG.LY with directly hosted U2NetP + ONNX Runtime. The wrapper embedded a vulnerable legacy Zod release; removing the wrapper eliminates that dependency rather than hiding the audit. Model/runtime files are same-origin and versioned, so uploads never reach a third-party model host. Browser preprocessing reduces images to a 1400 px long edge and keeps the multipart payload below Vercel's body limit. Export canvas dimensions do not imply added source detail.
- The automatic approval reviewer rejected public repository creation as unauthorized public source disclosure. Use a private repository; public visibility remains a human decision. No source was published publicly by that rejected command.
- With the AGPL wrapper removed, first-party code is MIT licensed. ONNX Runtime is MIT and U2Net uses Apache-2.0; their license files are committed beside their runtime assets. Third-party photographs retain their own license.
- Final unmodified shared perf-check succeeded after its clean rebuild: worst LCP 724 ms. The earlier Turbopack failure was environmental/cache-related, not a reason to bypass the gate.
- Added durable image reservations with daily interrupted-job refund, and a least-privilege data-only database role. The migration owner URL stays local and is not sent to Vercel.
- Live button testing found that an object-store redirect could open the image instead of saving it. Downloads now read a short-lived signed object URL server-side and stream through the same-origin route with explicit attachment disposition. This adds small Vercel egress but provides reliable browser downloads without exposing storage credentials.
